# NEXORA Premium Starter — Shopify

Thème Shopify Online Store 2.0, pensé à partir de la maquette fournie.

## Important
- L'image `assets/hero-reference.jpg` est une image temporaire extraite de la maquette. Remplace-la dans l'éditeur Shopify par tes vraies photos.
- Le thème ne contient pas tes produits, commandes, menus, clients ou données Shopify.
- Les textes de caractéristiques doivent être remplacés par des informations exactes et vérifiées.

## Connexion GitHub
1. Crée un dépôt GitHub et mets tous les fichiers de ce dossier à la racine du dépôt.
2. Dans Shopify : Boutique en ligne → Thèmes → Ajouter un thème → Connecter depuis GitHub.
3. Sélectionne le dépôt puis la branche.
